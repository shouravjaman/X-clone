# X-clone
This is a responsive recreation of the X homepage interface to gain hands on experience about Tailwind CSS. It is built with HTML
and Tailwind CSS. This project focuses on the UI and responsiveness to adapt in different screen sizes.

# Features

- Responsive three-column desktop layout

- Collapsible icon-only sidebar at medium screen widths

- Mobile header with a centered X logo

- Fixed mobile bottom navigation

- Scrollable feed 

- Video post with native browser controls

- Tailwind CSS utility classes for layout, spacing, colors, and
  breakpoints


# Built With

- HTML

- Tailwind CSS

- Vite

- Material Symbols

- A small amount of local image, SVG, and video assets

# Responsive Layout

**The interface adapts at different screen widths:**

**Mobile:** Feed-focused layout, mobile header, and bottom
navigation.

**Medium screens:** Compact icon sidebar and feed.

**Large screens:** Sidebar expands and the right-side panel appears
according to the configured breakpoints.

**This project helped me practise:**

- Building a page layout with CSS Grid and Flexbox

- Using Tailwind CSS utility classes and responsive breakpoints

- Creating mobile and desktop navigation layouts

- Managing scrolling, overflow, fixed positioning, and sticky elements
